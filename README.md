# Play Store Rating Prediction

A machine learning-based analytics project focused on predicting application ratings using historical Play Store data. The project applies data preprocessing, feature engineering, predictive modeling, and model interpretation techniques to generate meaningful insights from application-related information.

---

## Overview

This project explores factors associated with application ratings by analyzing structured app metadata and user review information. The workflow includes data preparation, feature transformation, model development, prediction, and explainability, presented through an interactive web application.

---

## Key Features

- Data preprocessing and cleaning
- Feature engineering
- Predictive machine learning model
- Explainable AI for model interpretation
- Interactive Streamlit application
- Automated rating prediction

---

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- SHAP
- Joblib

---

## Application

The project includes an interactive Streamlit application that enables users to provide application-related information and obtain a predicted rating generated by the trained machine learning model.
